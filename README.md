# Chronomedi

O **Chronomedi** é um sistema IoT inteligente para gerenciamento de medicamentos que sincroniza schedules multi-slot com um aplicativo mobile, acionando servo motores, LEDs indicativos e alarmes sonoros no hardware para guiar as doses com precisão e confiabilidade, mesmo em cenários com suporte a horário offline e sincronização em nuvem.

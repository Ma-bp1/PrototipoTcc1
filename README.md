# Chronomedi

O ChronoMedi é um ecossistema inteligente de saúde que une um aplicativo e uma caixa organizadora conectada para transformar a gestão de medicamentos no dia a dia.
Enquanto o app permite programar horários, enviar alertas personalizados e acompanhar o histórico de uso em tempo real, a caixa física atua diretamente na rotina do paciente, sinalizando o momento exato da dose e garantindo que o remédio certo seja tomado na hora certa. Juntos, hardware e software reduzem esquecimentos, evitam erros de dosagem e oferecem muito mais autonomia para os pacientes.
